# Портфолио

Портфолио веб-разработки и графического дизайна: сайты, фирменный стиль, печатные материалы, иллюстрации и моушн-дизайн.

**[Открыть сайт →](https://offlayt.github.io/)**

Сайт написан на HTML, CSS и JavaScript с ES-модулями. Сборки, npm-зависимостей и серверной части нет; готовые файлы публикуются на GitHub Pages.

## Что внутри

- Галерея работ с поиском, фильтрами, адаптивной сеткой, просмотром изображений и видео. Для отдельных проектов доступны подробные кейсы.
- Интерьерная сцена: тёмные обои, подвесная лампа, телевизор с зацикленным видео и радио с музыкой.
- Контакты в виде телефонной книжки и сцены с телефоном; мобильное меню оформлено дверцей шкафа.
- Загрузчик с логотипом: копии последовательно раскрываются, складываются обратно и повторяют цикл с паузами до готовности страницы.

Музыка запускается только нажатием на радио. Видео воспроизводятся без звука. Интерфейс учитывает системную настройку уменьшения движения.

## Локальный запуск

Из корня репозитория запустите HTTP-сервер. Например, с Python 3:

```sh
python -m http.server 8081 --bind 127.0.0.1
```

Откройте [localhost:8081](http://127.0.0.1:8081/). Открытие HTML двойным щелчком через `file://` не подходит: браузер ограничивает загрузку ES-модулей.

Node.js нужен только для проверок и служебных скриптов. Для работы самого сайта он не требуется.

## Структура

```text
index.html       Главная страница
case-*.html      Подробные кейсы
css/             Общие стили и стили компонентов
js/              ES-модули интерфейса
  data/          Каталог работ, услуги и плейлист
  portfolio/     Галерея, поиск, сетка и просмотр материалов
  lamp/          Физика, освещение и втягивание лампы
  footer/        Телевизор, радио и эквалайзер вкладки
assets/          Оптимизированные изображения, видео и музыка
demos/           Материалы демонстраций сайтов
docs/            Устройство компонентов и сведения о материалах
scripts/         Проверки и синхронизация загрузчика
```

Запуск компонентов главной страницы собран в [js/main.js](js/main.js). Подробная карта модулей — в [docs/structure.md](docs/structure.md).

## Обновление содержимого

**Работы.** Каталог находится в [js/data/project-catalog.js](js/data/project-catalog.js). Материалы добавляются в `assets/works/` или соответствующую папку демонстрации. У проекта указываются название, описание, категории и слайды; `caseHref` связывает его с отдельной страницей кейса. Категории и правила доступа к кейсам задаются в [js/data/projects.js](js/data/projects.js).

**Услуги.** Тексты и состав карточек находятся в [js/data/services.js](js/data/services.js).

**Радио.** Положите запись в `assets/radio/` и добавьте путь в [js/data/radio-tracks.js](js/data/radio-tracks.js). Треки играют по порядку; после последнего радио выключается. [Подробнее о плейлисте](assets/radio/README.md).

**Загрузчик.** Стили хранятся в [css/shared/page-loader.css](css/shared/page-loader.css), ожидание готовности страницы — в [js/page-loader.js](js/page-loader.js). После изменения стилей или разметки генератора обновите встроенные блоки на главной и страницах кейсов:

```sh
node scripts/sync-page-loader.mjs
```

[Временная шкала и поведение загрузчика](docs/page-loader.md).

## Проверки

Основные проверки запускаются из корня репозитория:

```sh
node scripts/check-site.mjs
node scripts/check-portfolio.mjs
node scripts/check-masonry.mjs
node scripts/check-navigation-and-order.mjs
node scripts/check-viewer-and-lamp.mjs
node scripts/check-contact-placement.mjs
node scripts/check-radio.mjs
node scripts/check-radio-title.mjs
node scripts/check-page-loader.mjs
node scripts/check-camera-cycle.mjs
```

Они проверяют ссылки и регистр имён файлов, каталог, размещение карточек, навигацию, контакты, радио и цикл загрузчика. Изменения внешнего вида дополнительно проверяются в браузере на широком и узком экранах.

## Публикация

Изменения отправляются в `dev`, затем оформляется pull request в `main`. В публикуемом дереве используются подготовленные WebP, MP4 и постеры. Локальные исходники в `.source-media/`, временные файлы и результаты проверок исключены через `.gitignore`.
