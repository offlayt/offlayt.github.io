# Структура исходников

Сайт остаётся статическим: HTML, модули JavaScript и CSS без сборки. Файлы входа только подключают компоненты в определённом порядке.

- `js/main.js` — запуск компонентов главной страницы.
- `js/navigation/` — меню шкафа и определение текущей секции.
- `js/portfolio/` — модель поиска, сортировка, карточки, masonry, воспроизведение и просмотр.
- `js/services/`, `js/lamp/`, `js/contacts/`, `js/cases/` — независимые блоки сайта.
- `js/core/` — общие DOM-функции, диалоги, математика и настройки движения.
- `js/data/` — каталог и тексты. Большой `project-catalog.js` содержит только декларативные материалы, без поведения и DOM-кода.
- `css/landing.css`, `css/contact-panel.css`, `css/portfolio.css` — короткие точки входа.
- `css/base/` — токены, сброс, общий макет и анимации появления.
- `css/navigation/`, `css/services/`, `css/sections/`, `css/lamp/`, `css/contacts/`, `css/portfolio/`, `css/cases/` — стили компонентов с их адаптивными правилами.
- `css/shared/` — общие диалоги и освещение поверхностей.
- `assets/navigation/` — сгенерированный шкаф; `assets/works/` — материалы портфолио.
- `assets/services/design/` — демонстрационные иллюстрации дизайн-услуг; [происхождение и промпты](design-images.md).
- `scripts/` — проверки каталога, геометрии, сортировки и границ активных секций.

При выделении CSS сохранён исходный порядок правил. Старые большие файлы теперь подключают модули через `@import`, поэтому дополнительных команд сборки не требуется. Переиспользуемый контроллер диалога сохраняет фокус и блокировку прокрутки; длительность закрытия можно задать для отдельного компонента.

В режиме «Все работы» сначала идут проекты с настоящими видео, затем проекты без видео. В каждой группе число уникальных материалов убывает; страницы разворота считаются отдельно, повторные источники — один раз. Равные результаты сохраняют порядок исходного каталога. Категорийные фильтры используют прежний порядок.

На hero активная ссылка отсутствует. После прохождения начала секции под хедером выбирается её ссылка. Возврат наверх снова сбрасывает выбор.

`js/lamp/hero-power.js` управляет питанием лампочки по границе hero под хедером: вне hero свет выключен, при возвращении включается. Физика подвеса остаётся в контроллере лампы.

`js/portfolio/viewer-dismiss.js` отделяет нажатия по видимому изображению от пустых полей `object-fit: contain`, учитывает масштаб и перетаскивание. Кнопки и управление видео сохраняют своё поведение.

В меню показывается только внутренняя сторона дверцы. Текстура дерева хранится в `assets/navigation/`, петли и таблички оформлены CSS. Анимация открытия и затухающих покачиваний находится в `css/navigation/wardrobe.css`; при сокращённом движении дверца сразу занимает конечное положение.

`js/services/web-deck.js` управляет только выбором карточки и её описанием; шаблоны вынесены в `templates.js`, содержание — в `js/data/services.js`. Кнопка выбора не раскрывает описание ни при фокусе, ни при наведении. Единственная точка раскрытия — отдельная кнопка «...». Стили стопки и адаптивные правила собраны в `css/services/web-deck.css` без повторяющихся блоков переопределения.
