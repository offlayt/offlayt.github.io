# Экран загрузки

Загрузчик главной и 11 кейсов показывает отдельную сгенерированную старую складную камеру: кожа, мех и латунный объектив. Видимых надписей, процентов и логотипа нет. Доступное имя «Загрузка страницы» остаётся только для скринридеров.

Цикл 1,8 с использует три целых изображения камеры: фронт → левый ракурс → фронт → правый ракурс → фронт. Ракурсы выровнены по оптическому центру; 144-мс переходы соединяют небольшие паузы на каждой стороне. Начальные и конечные положения и непрозрачности совпадают, на границе есть короткая фронтальная пауза. При готовности страницы камера складывается в четвёртое сгенерированное состояние, если оно декодировано, и фон растворяется. При отсутствии дополнительного кадра показывается обычное растворение без ожидания.

Изображение assets/loading/antique-camera.webp — WebP 480×480 с прозрачностью, 69 696 байт. Создано встроенным image_gen, затем только уменьшено и конвертировано с сохранением альфа-канала. Исходный PNG оставлен в стандартной папке generated_images. Предзагрузка изображения указана прямо в head; готовность декодирования камеры включена в ожидание.

Критический CSS и запуск находятся в HTML, поэтому тёмный экран появляется до загрузки внешних стилей. Источник — css/shared/page-loader.css; после изменения выполнить node scripts/sync-page-loader.mjs, чтобы синхронизировать 12 страниц без дублирования блоков.

Добавлены antique-camera-left.webp (62 848 байт), antique-camera-right.webp (59 800 байт) и antique-camera-closed.webp (61 276 байт), каждый 480×480 с альфа-каналом. Все четыре состояния суммарно весят 253 620 байт. Боковые состояния начинают анимироваться только после декодирования обоих файлов. Вторичные изображения загружаются с низким приоритетом и не входят в условия показа страницы.

js/page-loader.js ждёт инициализации главной, шрифтов, фронтальной камеры, изображений в текущем окне и обоев. Нижние изображения и видео не задерживают показ. На быстром соединении минимальный показ — 340 мс, растворение занимает 480 мс. Встроенный предохранитель открывает сайт через 6 секунд даже при недоступном скрипте, приложении или зависшем шрифте. Контент получает inert на время ожидания; исходные inert-состояния сохраняются. Без JavaScript заставка скрыта. Сокращённая анимация убирает движения и минимальную задержку. Восстановление из bfcache не повторяет заставку. Анимации карточек начинаются после открытия страницы.

Проверки: node scripts/check-page-loader.mjs и node scripts/check-camera-cycle.mjs. Цикл проверяется в 401 фазе: сумма непрозрачностей равна единице, крайние кадры и позиции совпадают. Дополнительно в браузерном CSS-движке проверены фазы 0, 24, 70, 99,9, 100, 100,1 и 200%, боковые ракурсы и финальное сложение. Покрыты готовность первого экрана, исключение нижних изображений, ошибки декодирования, зависшие шрифты, недоступный main, снятие блокировки, reduced motion, bfcache, отсутствие видимого текста и PNG-логотипа.
