# Экран загрузки

Сначала показывается чёрно-белый логотип камеры, затем фронтальный старый фотоаппарат. У каждого изображения шесть полноценных копий последовательно выходят из исходного положения и плавно движутся вниз поверх основного изображения. Они частично перекрываются, имеют разную яркость и постепенно исчезают. Смена двух форм проходит под слабой локальной вспышкой. Полный бесшовный цикл — 2,4 с.

Все копии идут по одной траектории вниз на 110% своей высоты, с задержкой 0/44/88/132/176/220 мс. Поэтому они не обгоняют друг друга: старейшая копия ниже и темнее, новая ближе к исходнику и выше по z-index. По мере движения масштаб уменьшается до 92%; яркость копий снизу вверх — 48/56/64/73/82/92%. Положение и прозрачность анимируются отдельными плавными кривыми. Максимальная непрозрачность — 98%. Исходное изображение слегка сжимается до 96,5% и возвращается в размер к вспышке. Все копии затухают до начала смены формы на 46%/96% цикла. В начале и конце цикла логотип виден полностью, копии и вспышка скрыты. При готовности страницы текущая фаза замораживается и заставка растворяется. Минимальное ожидание — 340 мс.

Используются только antique-camera.webp и существующий studio-camera-logo.png. Четырнадцать DOM-изображений используют два URL без дополнительных загрузок файлов для копий. Визуальная ширина камеры и логотипа выровнена; размер ограничен 32vh, чтобы каскад помещался на коротких экранах. Видимого текста нет; имя для скринридера сохранено. Вспышка — радиальное пятно с максимальной непрозрачностью 16%, без яркой полноэкранной заливки.

Критические стили встроены в 12 страниц. Источник css/shared/page-loader.css; node scripts/sync-page-loader.mjs синхронизирует HTML. Логотип предзагружается первым. js/page-loader.js ждёт приложения, шрифтов, двух изображений загрузчика, текущего экрана и обоев. Нижние медиа не задерживают показ. Предохранитель открывает страницу через 6 секунд при сбое. Если недоступна одна из двух картинок, показывается доступная. Сохраняются исходные inert-состояния; без JavaScript заставка скрыта. Reduced motion отключает движения и вспышки; bfcache не повторяет заставку.

Проверки: node scripts/check-page-loader.mjs и node scripts/check-camera-cycle.mjs. Проверяются 401 фаза, порядок логотип → фотоаппарат, общая траектория, последовательность задержек, слоёв и яркости, завершение каскада до смены формы, слабая вспышка, стык повторения, сбои ресурсов и снятие блокировки страницы.
