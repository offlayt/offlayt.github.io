# Экран загрузки

Загрузчик главной и 11 кейсов показывает отдельную сгенерированную старую складную камеру: кожа, мех и латунный объектив. Видимых надписей, процентов и логотипа нет. Доступное имя «Загрузка страницы» остаётся только для скринридеров.

Камера поворачивается в перспективе, на короткое время разделяется на три горизонтальных слоя с разной глубиной, собирается обратно и поворачивается в другую сторону. Позади остаётся мягкий след предыдущего положения, по корпусу проходит тёплый блик, под камерой меняется эллиптическая тень. Диафрагмы, рамки фокусировки и полосы прогресса нет. Цикл 1,6 с бесшовный; первое разделение происходит примерно через 0,38 с. При готовности страницы слои собираются, камера слегка уходит в глубину, тёмный фон растворяется.

Изображение assets/loading/antique-camera.webp — WebP 480×480 с прозрачностью, 69 696 байт. Создано встроенным image_gen, затем только уменьшено и конвертировано с сохранением альфа-канала. Исходный PNG оставлен в стандартной папке generated_images. Предзагрузка изображения указана прямо в head; готовность декодирования камеры включена в ожидание.

Критический CSS и запуск находятся в HTML, поэтому тёмный экран появляется до загрузки внешних стилей. Источник — css/shared/page-loader.css; после изменения выполнить node scripts/sync-page-loader.mjs, чтобы синхронизировать 12 страниц без дублирования блоков.

Четыре изображения используют один URL и один закешированный WebP, дополнительных файлов для слоёв нет.

js/page-loader.js ждёт инициализации главной, шрифтов, камеры, изображений в текущем окне и обоев. Нижние изображения и видео не задерживают показ. На быстром соединении минимальный показ — 340 мс, растворение занимает 480 мс. Встроенный предохранитель открывает сайт через 6 секунд даже при недоступном скрипте, приложении или зависшем шрифте. Контент получает inert на время ожидания; исходные inert-состояния сохраняются. Без JavaScript заставка скрыта. Сокращённая анимация убирает движения и минимальную задержку. Восстановление из bfcache не повторяет заставку. Анимации карточек начинаются после открытия страницы.

Проверки: node scripts/check-page-loader.mjs. Покрыты готовность первого экрана, исключение нижних изображений, ошибки декодирования, зависшие шрифты, недоступный main, снятие блокировки, reduced motion, bfcache, отсутствие видимого текста и PNG-логотипа.
