# Экран загрузки

На тёмном фоне только чёрно-белый логотип камеры, без текста, вспышек и реалистичного фотоаппарата. Полный цикл — 4 секунды:

- 0–160 мс: исходный логотип плавно увеличивается до 104%.
- 160–640 мс: шесть копий раскрываются по очереди сверху вниз, каждое движение длится 80 мс. Каждая появляется из конечной позиции предыдущей, затем останавливается. Позиции — 13/26/39/52/65/78% высоты, без отрыва; следующая копия находится выше предыдущей по z-index.
- 640–1280 мс: полная стопка остаётся на месте, пауза 640 мс.
- 1280–1760 мс: копии складываются в обратном порядке, снизу вверх. Каждая возвращается к предыдущей и исчезает; обратное движение также по 80 мс.
- 1760–1920 мс: исходный логотип плавно возвращается к 100%.
- 1920–4000 мс: только неподвижный логотип, пауза 2080 мс, затем повтор.

Исходник остаётся самым ярким. Яркость копий сверху вниз — 92/82/73/64/56/48%. Плавный разгон и остановку задаёт cubic-bezier(.32,0,.5,1). У всех копий общая временная шкала без animation-delay: предыдущие итерации не оставляют видимых кадров в начале нового цикла. Начальные и конечные состояния совпадают. При готовности страницы текущая фаза замораживается и заставка растворяется; окончания цикла ждать не нужно. Минимальное ожидание — 340 мс.

Используется один существующий studio-camera-logo.png; семь DOM-изображений повторно используют один URL. Размер ограничен 32vh, чтобы раскрытая стопка помещалась на коротких экранах. Видимого текста нет; имя для скринридера сохранено.

Критические стили встроены в 12 страниц. Источник css/shared/page-loader.css; node scripts/sync-page-loader.mjs синхронизирует HTML. Логотип предзагружается. js/page-loader.js ждёт приложения, шрифтов, логотипа, изображений текущего экрана и обоев. Нижние медиа не задерживают показ. Предохранитель открывает страницу через 6 секунд при сбое. Ошибка логотипа не блокирует показ страницы. Сохраняются исходные inert-состояния; без JavaScript заставка скрыта. Reduced motion отключает анимацию; bfcache не повторяет заставку.

Проверки: node scripts/check-page-loader.mjs и node scripts/check-camera-cycle.mjs. Проверяются последовательность появления и обратного складывания, координаты предыдущей копии, затемнение вниз, обе паузы, отсутствие видимых копий между повторами, ошибки ресурсов и снятие блокировки страницы.
