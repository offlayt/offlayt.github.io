# Экран загрузки

Сначала показывается чёрно-белый логотип камеры, затем фронтальный старый фотоаппарат. У каждого изображения три полноценные копии последовательно выходят из исходного положения и непрерывно движутся вниз поверх основного изображения. Они частично перекрываются, имеют разную яркость и постепенно исчезают; это каскад изображений, а не тень за неподвижным рисунком. Смена двух форм проходит под слабой локальной вспышкой. Полный бесшовный цикл — 3,6 с.

Главное изображение остаётся неподвижным и не затемняется. Копии имеют z-index выше главного, смещаются на 36%, 64%, 92% своей высоты и стартуют с задержкой 0/90/180 мс. Положение анимируется линейно, прозрачность — отдельной плавной кривой. Максимальная непрозрачность копии — 98%; яркость ближней/средней/дальней — 88%/72%/58%. В начале и конце цикла логотип виден полностью, копии и вспышка скрыты. При готовности страницы текущая фаза замораживается и заставка растворяется. Минимальное ожидание — 340 мс.

Используются только antique-camera.webp и существующий studio-camera-logo.png. Восемь DOM-изображений используют два URL. Визуальная ширина камеры и логотипа выровнена; размер ограничен также высотой окна для коротких экранов. Видимого текста нет; имя для скринридера сохранено. Вспышка — радиальное пятно с максимальной непрозрачностью 16%, без яркой полноэкранной заливки.

Критические стили встроены в 12 страниц. Источник css/shared/page-loader.css; node scripts/sync-page-loader.mjs синхронизирует HTML. Логотип предзагружается первым. js/page-loader.js ждёт приложения, шрифтов, двух изображений загрузчика, текущего экрана и обоев. Нижние медиа не задерживают показ. Предохранитель открывает страницу через 6 секунд при сбое. Если недоступна одна из двух картинок, показывается доступная. Сохраняются исходные inert-состояния; без JavaScript заставка скрыта. Reduced motion отключает движения и вспышки; bfcache не повторяет заставку.

Проверки: node scripts/check-page-loader.mjs и node scripts/check-camera-cycle.mjs. Проверяются 401 фаза, порядок логотип → фотоаппарат, непрерывность позиций, каскад перед исходным изображением, слабая вспышка, стык повторения, сбои ресурсов и снятие блокировки страницы.
