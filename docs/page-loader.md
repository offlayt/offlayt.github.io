# Экран загрузки

На тёмном фоне показывается статичный фронтальный старый фотоаппарат. Три его копии плавно смещаются вниз, затемняются и исчезают. Под слабой локальной вспышкой камера заменяется исходным чёрно-белым логотипом той же визуальной ширины. Логотип повторяет шлейф; вторая вспышка возвращает старую камеру. Полный бесшовный цикл — 2,8 с. Текста и процентов на экране нет; доступное имя остаётся только для скринридеров.

Используются только antique-camera.webp (69 696 байт) и существующий studio-camera-logo.png. Каждая картинка повторяется четырьмя DOM-элементами, но URL всего два. Боковые и сложенное состояния в этой анимации не запрашиваются. Главный силуэт затемняется до 72%, копии фотоаппарата имеют максимальные непрозрачности 36%, 24%, 14%, логотипа — 24%, 15%, 8%. Вспышка ограничена мягким радиальным пятном с максимальной непрозрачностью 16%, без полноэкранной заливки. Анимируются opacity и transform.

Ритм двух половин совпадает со сдвигом 1,4 с. В конце и начале цикла старая камера полностью видна, копии и вспышка скрыты; позиции совпадают. При готовности страницы текущая фаза замораживается и заставка плавно растворяется. Минимальное ожидание — 340 мс, длинная загрузка повторяет цикл.

Критический CSS и запуск встроены в HTML. Источник — css/shared/page-loader.css; node scripts/sync-page-loader.mjs синхронизирует 12 страниц. js/page-loader.js ждёт приложения, шрифтов, двух изображений загрузчика, текущего экрана и обоев. Изображения и видео ниже по странице не задерживают показ. Встроенный предохранитель открывает сайт через 6 секунд при сбое. Если логотип не загрузился, остаётся камера со шлейфом. Исходные inert-состояния сохраняются; без JavaScript заставка скрыта. Reduced motion отключает движения, вспышки и минимальную задержку. bfcache не запускает заставку повторно.

Проверки: node scripts/check-page-loader.mjs и node scripts/check-camera-cycle.mjs. Проверяются 401 фаза, чередование двух форм, стык шлейфа, слабая вспышка, недоступный логотип, ошибки ресурсов, очистка inert, таймаут, reduced motion и bfcache.
