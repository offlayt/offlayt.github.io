# Демонстрационные изображения дизайн-услуг

Шесть иллюстраций созданы встроенным ImageGen для карточек услуг. Это демонстрационные макеты; материалы реальных проектов в портфолио не заменялись.

Все файлы находятся в `assets/services/design/`: WebP, 1254 × 1254, с прозрачным альфа-каналом. При сохранении изменён только формат, без кадрирования и изменения композиции.

| Файл | Карточка |
| --- | --- |
| `brand-identity.webp` | Фирменный стиль |
| `business-cards.webp` | Визитки |
| `logo-design.webp` | Логотип |
| `advertising-graphics.webp` | Реклама и графика |
| `mascots-stickers.webp` | Маскоты и стикеры |
| `presentations.webp` | Презентации |

[Точный набор промптов](design-image-prompts.json). Подключение изображений — `js/data/services.js`; шаблон и адаптивные стили — `js/services/templates.js` и `css/services/design.css`.
