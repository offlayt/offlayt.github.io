# Музыка радиоприёмника

Место для MP3, который пользователь добавит позже. После получения записи сохранить её как `assets/radio/music.mp3` и задать `data-radio-src="assets/radio/music.mp3"` у `.radio-button` в `index.html`.

Пока `data-radio-src` пуст, нажатие включает только тихий шум настройки; отсутствующий файл не запрашивается. Музыка запускается только после нажатия, повторяется и проходит через фильтры радиоприёмника и плавное изменение громкости. Повторное нажатие плавно выключает звук.
