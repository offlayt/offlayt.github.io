# Музыка радиоприёмника

Текущая запись — `el-problema.mp3` (около 27 секунд, 440 КиБ). Она загружается только после нажатия на радио.

Порядок записей задан в [плейлисте](../../js/data/radio-tracks.js). Чтобы добавить музыку, положите MP3 в эту папку и добавьте его путь относительно `index.html` в массив `radioTracks`. Статический сайт не сканирует папку автоматически. Проверка `node scripts/check-site.mjs` проверяет существование всех записей.

После окончания трека запускается следующий. После последнего радио плавно выключается вместе с шумом и подсветкой; новое нажатие запускает плейлист сначала. Повторное нажатие во время музыки плавно выключает звук, сохраняя позицию для продолжения. Музыка проходит через частотные фильтры и компрессор, тихий шум добавляет эффект радиоприёмника. При ошибке воспроизведения радио выключается.
